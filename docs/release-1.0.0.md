# EasyTodo 1.0.0 · 随手记，慢慢做

EasyTodo 首个正式版本：一款贴在 Windows 屏幕边缘、采用奶油手帐风格的本地待办工具。

## 新界面

- 奶油纸张、胶带便签、暖棕描边与笑脸清单图标。
- 浅色、深色及跟随系统主题，侧边书签把手同步切换。
- 圆角透明窗口与适配屏幕边缘的杏色书签把手。

## 核心功能

- 文字、截图、截图加说明；粘贴即记录，Enter 即保存。
- 全局快捷键 Ctrl+Alt+Space；悬停书签展开且不抢焦点。
- 按日期分组，完成归档、撤销、恢复、编辑与图片放大。
- 本地 JSON 与图片存储，无账号和云端依赖。
- 系统托盘、可选开机启动、自定义快捷键与多显示器适配。

## 安装

适用于 Windows 10 / 11 x64。下载下方的 **EasyTodo-Setup-1.0.0-x64.exe** 并运行，无需 Node.js。可使用 SHA256SUMS.txt 核对安装包完整性。

现有安装版可先从托盘退出后更新。数据目录默认是 `%APPDATA%\EasyTodo`；早期开发版可能使用 `%APPDATA%\easy-todo`，迁移前请备份 `todos.json` 和 `images` 文件夹。

安装包未进行 Windows 代码签名。本版本不包含自动更新功能。
