# EasyTodo 1.0.1

本次更新让截图查看与复制更方便，并在托盘菜单中加入重新启动。

## 更新内容

- 双击待办图片后，在独立的全屏窗口中查看；按 Esc、点击关闭按钮或点击图片外区域返回面板。
- 在待办图片、编辑弹窗中的图片和全屏图片上右键，可选择“复制图片”。
- 托盘图标右键菜单新增“重新启动”。

## 安装

适用于 Windows 10 / 11 x64。下载 **EasyTodo-Setup-1.0.1-x64.exe** 并运行。已有用户可先从托盘退出旧版本再安装；待办和图片数据保存在 `%APPDATA%\EasyTodo`，升级不会清空数据。

安装包未进行 Windows 代码签名。本版本不包含自动更新功能。可使用 SHA256SUMS.txt 核对安装包完整性。
